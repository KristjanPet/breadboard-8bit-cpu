# Transistor XOR Gate

A two-input XOR gate built with discrete transistors. The LED turns on when the inputs are different.

## Truth Table

| Input A | Input B | Output | LED |
| ------: | ------: | -----: | --- |
|       0 |       0 |      0 | OFF |
|       0 |       1 |      1 | ON  |
|       1 |       0 |      1 | ON  |
|       1 |       1 |      0 | OFF |
