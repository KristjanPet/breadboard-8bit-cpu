# Breadboard 8-Bit CPU

A learning project exploring computer architecture from the ground up.

The project starts with transistor logic gates, continues through adders, registers and an ALU, and eventually builds a working 8-bit CPU using 74HC logic chips.

## Progress

- [x] Transistor logic gates
- [ ] Half and full adder
- [ ] 1-bit ALU
- [ ] Registers and counters
- [ ] 8-bit ALU
- [ ] Control logic
- [ ] Working 8-bit CPU
